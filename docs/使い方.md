# EbookText Studio 使い方ガイド

Windows上で表示している電子書籍のページを撮影し、ローカルのOCRで文章（Markdown / テキスト / PDF）にするまでの手順です。詳しい仕様や制約は [README](../README.md) を参照してください。

> 閲覧権限のあるコンテンツを、法令・利用規約で許可される範囲でのみ使用してください。DRM解除や保護機能の回避には対応していません。

## 1. 初回準備（一度だけ）

**ソース版（推奨の標準手順）**

1. ZIPを展開し、`setup.bat` をダブルクリックします。Python・Tesseract・日本語データの導入、ライブラリのインストール、デスクトップ／スタートメニューのショートカット作成まで自動で行います（インターネット接続とwingetが必要。途中で許可の確認が出ることがあります）。
2. デスクトップの「EbookText Studio」ショートカット（または `run.bat`）でGUIを起動します。

**exe版（Python不要）**

1. 配布されたZIPを展開し、`install_ocr.bat` を一度だけ実行します（Tesseractと日本語データを導入）。
2. `EbookTextStudio.exe` をダブルクリックして起動します。
3. （自分でexeを作る場合）`setup.bat` のあとに `build_exe.bat` を実行すると `dist\EbookTextStudio` に作成されます。

> 自動セットアップとexe版はWindows実機で未検証です。失敗した場合は表示されたエラーを控えてください。wingetが使えない場合は [README](../README.md) の手動導入手順を参照してください。

## 2. 電子書籍を画面から撮影して文章にする

1. ビューア（Kindleなど）で本を開き、**単ページ表示・適切な拡大率**にして、取り込みたい最初のページを表示します。
2. GUIの **「① 保存先・書籍名」** で保存先と書籍名を入力します（書籍ごとにフォルダが分かれます）。
3. **「画面で撮影範囲を選択」** をクリックし、本文領域だけをドラッグで囲みます（Escでキャンセル）。上下が切れていないか確認してください。
4. **ページ送り** のキー（右矢印、PageDownなど）を、使っているビューアに合わせて選びます。
5. 最初は最大ページ数を**3〜5ページ**にして試し、待機秒数は1.5〜3秒程度で調整します。
6. **「▶ 自動キャプチャ開始」** を押し、カウントダウン中にビューアを前面にしてクリックします。撮影中はキーボードを操作しないでください。
   - **F8** で停止します。同じ画面が3回続くと自動で終了します。
   - 途中で止めても撮影済みの画像は残り、次回は続きのページを表示してから開始すると連番で追記されます。
7. アプリに戻り、**③** でOCRエンジン（まずは `Tesseract`）、言語（`jpn+eng`）、PSM（通常は3）を選んで **「▶ OCR / Markdown / PDF を生成」** を押します。
8. **「フォルダを開く」** で書籍フォルダを開き、`output` の中の成果物を確認します。

## 3. すでにある画像・PDFを文章にする

- 画像が入ったフォルダ → **「画像フォルダを取り込む」**（ファイル名順がページ順。例: `001.png`, `002.png`）
- PDF → **「PDFを取り込む」**（180dpiで画像化。選択可能なテキストが十分あるページは元のテキストを優先）

取り込み後は、手順2の7〜8と同じくOCRを実行します。

## 4. 出力ファイル

`保存先/書籍名/output/` に次のファイルができます。

| ファイル | 内容 |
| --- | --- |
| `全文.md` | Markdown。AIに読ませたいときに便利 |
| `全文.txt` | プレーンテキスト |
| `画像PDF.pdf` | 原画像のみのPDF |
| `検索可能PDF.pdf` | 原画像＋検索用の透明テキスト層つきPDF |
| `pages/page_00001.txt` ... | ページ別テキスト |

## 5. 誤認識の修正

書籍フォルダの `replacements.json` に置換ルールを書き、OCRを再実行すると反映されます。

```json
{"CKDl": "CKD1"}
```

誤った置換も起こり得るため、医療用語などの一括置換は慎重に行ってください。OCR結果は必ず原本と照合してください。

## 6. 複数冊をまとめて処理する（CLI）

```powershell
# 画像フォルダ（またはPDF）1冊
.venv\Scripts\python.exe cli.py one --input "C:\Books\my_pages" --base "C:\EbookText" --title "書名"

# フォルダ内のサブフォルダ／PDFを1冊ずつ処理
.venv\Scripts\python.exe cli.py batch --input "C:\Books\incoming" --base "C:\EbookText"
```

主なオプション: `--engine Tesseract|NDLOCR-Lite`、`--lang jpn+eng`、`--psm 3|4|6|11|12`、`--ndl-command`、`--no-native`（PDFの既存テキストを使わない）。

## 7. うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| 黒い画面が保存される | ビューアが画面撮影を保護しています。回避はできません |
| ページが飛ぶ／重複する | 待機秒数を増やす、ページ送りキーを確認する、スクロール式ビューアは非対応 |
| Tesseractが見つからない | `setup.bat`（exe版は `install_ocr.bat`）を再実行する。`C:\Program Files\Tesseract-OCR\tesseract.exe` の有無も確認 |
| 言語データが足りない | `setup.bat` / `install_ocr.bat` を再実行する。手動なら `jpn.traineddata` / `eng.traineddata` を `%LOCALAPPDATA%\EbookTextStudio\tessdata` に入れる |
| 文字がうまく読めない | 「画質補正」「小さい画像を拡大」を切り替える、PSMを4/6/11で試す、縦書きは `jpn_vert+eng` |

## 8. 開発者向け: テストの実行

GUIと画面撮影はWindows専用ですが、OCR・取り込み・PDF生成のテストはLinux/macOSでも実行できます（Tesseract本体が必要）。

```bash
sudo apt-get install -y tesseract-ocr tesseract-ocr-jpn
python3 -m venv .venv
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q tests
```

テストは手動で実行します（GitHub Actionsなどの自動テストは使いません）。
